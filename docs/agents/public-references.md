# No repository references in public copy

Nothing public may point into a private repository. Public copy never cites an issue or pull request number ("#123") or links to the repository: docs, the blog, the changelog, marketing pages, product UI strings, emails, API descriptions, and everything that ships to npm (package READMEs, changelogs, package source). Describe the change itself instead. Code comments in application source, internal docs, commit messages and PR descriptions may keep their numbers.
